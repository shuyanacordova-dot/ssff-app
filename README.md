# SSFF App

Sistema operativo para ShuVision y Focus.

Este repositorio contiene la nueva versión del sistema, construida por bloques y mantenida bajo control de versiones.

## Arquitectura inicial

- Next.js + TypeScript
- Supabase Auth/Postgres
- Notion como fuente de datos operativos
- Vercel para despliegue

## Regla de desarrollo

Cada bloque debe quedar funcional y versionado antes de continuar con el siguiente.
